# 家庭用药管理工具

为家人长期打针、每日服药的真实需求设计的两个网页应用（PWA），可以添加到手机桌面，像普通 App 一样使用。

- **打针记录**：记录每次打针的日期，提醒下一次打针时间
- **吃药打卡**：每日服药打卡，没打卡时在睡前补提醒

## 解决的问题

**iPhone 上的网页应用无法定时推送通知。** 用户需要的是“吃了就别再提醒，没吃才提醒”，单靠网页做不到。

**方案：网页 App 打卡 + iOS 快捷指令定时检查**

1. 用户在网页 App 里打卡
2. iOS 快捷指令每天在睡前定时运行，检查当天是否已经打卡
3. 已打卡：不提醒；未打卡：弹出提醒
4. 手机处于静音模式时，可选用语音朗读提醒

## 隐私设计

- 所有记录只保存在用户自己的手机上（浏览器本地存储），不上传到任何服务器
- 仓库中的代码是公开的，但不包含任何健康记录
- 提供导出和恢复功能，换手机时不会丢失记录

## 面向老年用户的迭代

目标用户是家中长辈，所以：

- 按照对方手机（iOS 26）的实际界面编写快捷指令的设置步骤
- 根据对方发来的截图反馈，多次修改操作指引的措辞和步骤
- 加入静音模式下的语音提醒
